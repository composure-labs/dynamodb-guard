# Security Policy

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/composure-labs/dynamodb-guard/security/advisories/new), not in a public issue.

## Supported versions

| Version | Receives fixes                                 |
| ------- | ---------------------------------------------- |
| 1.x     | The latest minor release only                  |
| 0.x     | None, once 1.0.0 is published. Upgrade to 1.x. |

A fix ships as a patch on the latest minor. Upgrading within 1.x is meant to be safe: see [Versioning](README.md#versioning) for what a minor release can change.
